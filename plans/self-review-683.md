## Post-round-2 self-audit: the denominator

Round 3 was requested and, while it was in flight, I started ticket #687. Its first deliverable is a disposition for every live finding, so the first thing it needs is a list of them. Nobody had enumerated that list since the ledger was written, including me. I enumerated it from the two review comments rather than from the ledger, because the ledger is what #687 is supposed to consume and consuming a table without checking it against its input is what produced L-6 and L-10.

The ledger does not partition either review. #668 has 21 distinct finding IDs and the ledger accounts for 19; #672 has 19 and the ledger accounts for 17. Four findings are in neither the remediated column nor the live column. Worse, the sentence under the table claims 24 live from #668, and 24 is not a number any reading of the source can produce -- 21 findings with one remediated caps the live count at 20, and the ledger's own rows enumerate 18. So the prose disagreed with the table, and the table disagreed with the source, and H1's denominator of 57 was the prose figure plus the new findings.

I want to be clear about which part of this bothers me, because it is not the arithmetic. Three checking passes ran over this artifact before I found it: two hostile-review rounds and my own rubric self-falsification, which explicitly went looking for count defects after L-7. All three verified totals against the table. That is the natural thing to do and it cannot work here, because the table is the incomplete object. **A recount that starts from the artifact cannot find a finding the artifact never mentions.** The check that would have caught it -- enumerate the source's IDs, enumerate the table's, assert set equality -- takes one command and nobody ran it, including in the pass I wrote specifically to catch this class.

That is a lesson about where checks start, not about how carefully they are run. L-11 said a control described in prose drifts from the control that executes. L-12 says a control that only ever reads the artifact cannot check the artifact against the world, however rigorously it reads.

I dispositioned all four by repro on the branch before publishing a corrected number, rather than assuming the direction that would have been convenient. All four are live, one partially, so the denominator is 55 and the threshold 28 rather than 57 and 29. The old threshold was *higher* than the evidence licensed, which is the conservative direction and is not a defence: a bar set by an unsupported figure is not a bar regardless of which way it errs, and if I had let the conservative direction excuse it I would have been arguing that an unchecked number is fine when it happens to be strict.

I told the round-3 reviewer mid-review rather than waiting for the review to land, because the reviewer had been asked to recount in exactly this area and would have spent the round re-deriving a number I already knew was wrong. The message named what was still sound -- the 28 new findings and their severity split, both re-verified -- so the rubric work it was actually there to do was not put in doubt along with the denominator.
