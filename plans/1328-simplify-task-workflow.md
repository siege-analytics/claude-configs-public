## Design

One task, one authorized outcome, actual target scope. Read enough to understand the change, choose a proportionate approach, implement, validate, review and deliver. Remove universal pre-edit companion-artifact and posting prerequisites. Keep session/task ownership, physical scope, truthful execution effects, genuine explicit holds and protected operations. Preserve real independent review for high-risk publication; remove fictional organizational ranks and compulsory mistake-finding. Pre-mortems become optional analysis tools, not permission signals. One compact review record captures goal, actual documentation/source consultation, the facts and reasoning that informed the change, assumptions, executed tests, findings and independent review when needed. The operator clarified that the original hooks responded to reckless agents and sought proof of consultation, research and effort. Preserve that evidentiary purpose while removing ceremony; links or flags alone are not proof of understanding. Existing evidence remains readable history, never fabricated or deleted to obtain admission.

## Risk and validation

Removing process machinery must not remove scope or actual operator protections. Exercise own/foreign task isolation, out-of-scope rejection, explicit holds, normal edit admission without ceremonial companions, and meaningful review requirements before publication. Reconcile prompt injection and commit/native enforcement with the authored policy. Run affected regression suites and build/reference checks; inspect any failure rather than disabling checks. Review source independently before merging. Runtime acceptance remains sustained scheduled outcomes and handoffs, not passing fixtures.

## Delivery

Publish through develop then main with actual checks/review. Install canonical generations through existing supported paths, preserve operator settings, and verify current remote behavior.
