## Design

Keep one recovery entrypoint. Put host-capability and deployment navigation in an ordinary sibling Markdown reference that both existing layouts copy. Route diagnosis through verified status and supported native controls before declaring an in-place repair impossible. Preserve authority boundaries, current-state reconciliation, no duplicate successors, durable handoff, actual successor response and bounded retirement. Keep the three observed failure shapes as diagnostics rather than proof of the current host's capabilities.

Replace categorical cannot-edit/cannot-interrupt claims with conditional repair decisions. A supported control is not an expanded grant, and a journal supersession does not cancel a live operation. Link the resolver using its canonical skill token rather than an authored-layout path.
