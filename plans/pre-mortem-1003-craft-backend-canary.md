# Pre-mortem: #1003 Craft/backend canary packet

## Scope

Prepare reviewable scripts, synthetic fixtures and an approval packet. Do not launch sessions, create/register a Craft workspace, run a host canary, inspect credentials, install, publish, mutate GitHub provider state, or claim live support.

## Failure modes and controls

1. **A design document or self-written flag is mistaken for approval.** Checked-in packet is proposal-only. A later record must bind an externally supplied direct operator instruction to exact prerequisites and materialized bytes, but the record and validator always have `authorization_effect: none`.
2. **A broad path damages shared state.** Run ID determines exact temp and workspace paths; aliases, relatives, `..`, arbitrary homes and pre-existing roots reject.
3. **Generated bytes differ from approved source.** Materialization checks a full source revision/tree digest, builds in a detached clone, checks canonical package content, records exact package-tree bytes, and requires re-attestation after authorization.
4. **Backend/model/imported text is mistaken for verified runtime evidence.** Evidence requires externally exported event artifacts, rejects model/synthetic relabeling, and reports only structural consistency with unverified provenance.
5. **Parallel runs confound side effects.** Exactly two distinct approved backend/model pairs run sequentially; overlapping timestamps reject.
6. **An inert adapter looks green.** Each backend must produce an explicit no-op detection event; missing event sets reject.
7. **Allowed/denied mutations are not distinguishable.** Host records before/after digests for one allowlisted write and one denied external write, plus local bare-remote ref changes/non-changes.
8. **Provider authority is inferred.** The packet declares no provider-authority claim; #1019 and required-protection evidence remain separate.
9. **Credentials leak into evidence.** Credential reading is prohibited; only redacted host metadata and artifact digests may be retained.
10. **Timeout leaves residue.** Per-run, transition, cleanup and overall deadlines are explicit; any timeout enters cleanup without in-place repair.
11. **Generic package files overwrite composed resolver data.** Assemble generic dependencies first, composition last, then invoke the final payload resolver and require strict-release plus both scoped skills.
12. **Resident presence is mistaken for delivery.** Probe the exact canonical registered hook after the separately reviewed selector render-mode correction integrates; require one resident marker and no negative controls without changing `CLAUDE_KERNEL_PATH` validation. Until then, keep the packet blocked rather than installing a parallel adapter.
13. **Local transport rewrites project identity.** Seed the bare fixture locally, retain canonical fetch identity plus an exact local bare push URL, reject `insteadOf`, and assert both resolver identity and local `main` ref consistency from the final fixture.
14. **Source or fixture drifts after an earlier attestation.** Setup reruns the shared materialized-byte attestation immediately before the first workspace copy/command and binds its receipt. Source-script, origin and push-transport mutations must reject before any payload target or install/wire/verify invocation.
15. **Approval recording changes its own subject.** Exclude lifecycle status/record fields only; compute after final pins and require substantive mutations to reject the stale external subject.
16. **Prefix markers corrupt evidence slices.** Match prescribed delimiters in actual user content, test no-op/restored and compaction before/after together, and initialize backend/evidence paths before creating the first receipt.
11. **Cleanup script deletes broadly.** The driver performs no deletion. Cleanup uses normal UI plus exact temp removal; verifier requires real absence and unchanged outside state.
12. **Prerequisite heads change.** Any replacement #1002/#845/develop/script/package identity requires packet refresh and fresh exact-head review.

## Rollback

Before live authorization: delete the feature branch/worktree through normal Git workflow. After an authorized run: end disposable sessions, remove only the exact workspace and temp root, verify refs/path absence and unchanged external state, then retain redacted digests only. Rollback cannot include `main`, protections, releases, installations or unrelated workspaces.
