## Design and boundaries

Turn binding is consumed only by the UserPromptSubmit diagnostic subprocess, after existing environment binding precedence. Bounded typed task metadata or an unfenced column-zero prompt directive selects an existing own-session canonical task identity. Conflicting, unknown, malformed, foreign-session or quoted/example bindings derive no companions. Other active Tasks remain unchanged. No per-action scope or Write/Edit binding is extended.

Artifact permission fallback validates the exact ticket repository, actual comment author and returned user login, then requires admin/maintain/write permission. It preserves own-actor/association fast paths, artifact classification and ticket/own-PR checks. Four reads, one-second per read and two seconds aggregate share the existing writer ceiling; failed/unknown/read/triage responses grant nothing. Untrusted fallback exhaustion cannot suppress older trusted-path artifacts.
